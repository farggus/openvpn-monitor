# Release Notes

This directory contains release notes for all versions of OpenVPN Monitor.

## Format

Release notes are stored in the format: `vX.Y.Z.md` (e.g., `v1.0.0.md`, `v1.1.0.md`)

## Available Releases

- [v1.0.0](v1.0.0.md) - Initial stable release (October 2025)

## Versioning

This project follows [Semantic Versioning](https://semver.org/):

- **MAJOR** version for incompatible API changes
- **MINOR** version for new functionality in a backward compatible manner
- **PATCH** version for backward compatible bug fixes

## Latest Release

The latest release notes can always be found in the most recent version file.
For GitHub releases, see: https://github.com/farggus/openvpn-monitor/releases
